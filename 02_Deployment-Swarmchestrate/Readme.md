# Deploy Swarmchestrate in Azure

## Prerequisites
- helm (package manager for Kubernetes)


## Installation
```bash
# clone the repository
git clone https://github.com/dos-group/swarmchestrate-alternative.git

# prepares cluster for Swarmchestrate
./boostrap all







# Load Balancer with static IPs on Cloud-nodes
./boostrap raft_lb






# remove the repository
sudo rm -r swarchestrate-alternative
```
